# AI_NOTES.md

## 1. Which parts were done by me and which parts were done using AI

I created the React frontend part first.

After that, I used an AI tool to improve the frontend code, organize the project structure, and help with the overall architecture.

The AI helped me create most of the Spring Boot backend, JUnit test cases, REST Assured API tests, and Selenium automation tests.

When I got errors, I used AI to understand the problem and find possible fixes.

## 2. What I checked, tested, or changed

I did not use the AI output directly without checking it.

I ran the backend and frontend and tested the login and expense features.

I also ran the JUnit, REST Assured, and Selenium tests.

I changed and fixed some parts after testing, such as:

- YAML indentation errors
- H2 database lock error
- Frontend failed-to-fetch error
- Test case failures
- Swagger setup
- Project folder structure
- API URLs and port settings

I made these changes because the project had to run correctly and follow the assignment structure.

## 3. AI suggestions I did not use

The AI gave some extra and more complex suggestions.

I did not use all of them because I wanted to keep the project simple and follow the assignment requirements.

For example, I did not use a separate database server or multiple Maven projects.

I kept one main `pom.xml` file and used the local H2 database.
